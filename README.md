# 🐍 SuperSnake

A modern, full-stack remake of the classic Snake game — reimagined with customizable gameplay, profile management, AI opponents, and even real-time multiplayer. Originally developed as a C# Windows Forms app, this new version uses **Java Spring Boot** for the backend and **React** for the frontend.

---

## 🎮 Features

### ✅ Core Gameplay
- Classic Snake game with modern adjustments
- Choose number of apples on screen (1–5)
- Toggle wall collision or edge wrapping
- Play solo or with a friend (2-player on same keyboard)

### 👤 User System
- Secure user registration and login
- Profile page with stats and match history
- Earn in-game coins through performance

### 🛍 In-Game Shop *(Coming Soon)*
- Purchase skins for snake, head, apples, and background
- Use coins earned during gameplay

### 🧠 AI Mode *(Planned)*
- Play 1v1 against an intelligent snake bot
- Adaptive behavior based on apple and obstacle positions

### 🌐 Online Multiplayer *(Planned)*
- Invite and play in real-time with friends
- Matchmaking system and private rooms

---

## 🧱 Tech Stack

### Backend (Java + Spring Boot)
- Spring Boot (REST API & WebSocket support)
- Spring Security + JWT (authentication)
- PostgreSQL (persistent storage)
- JPA/Hibernate (data access layer)

### Frontend (React + Canvas)
- React with Vite for fast development
- HTML5 Canvas for game rendering
- React Router (navigation)
- Tailwind CSS (styling)
